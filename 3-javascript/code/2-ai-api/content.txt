Why flex-grow is Important
If we remove flex-grow from the <main> component, the layout becomes messy because the main content no longer stretches to fill the available vertical space.
flex-grow makes the main component expand to fill the remaining height inside the parent container.
We can focus on the main container width by using the class w-full md:w-[768px].
What does this mean?
w-full
This sets the width to 100% for small devices (screen width below 768px).
md:w-[768px]
The prefix md: stands for medium breakpoint, which in Tailwind means a device with a minimum width of 768px.
So, when the screen size is 768px or larger, the width will be set to exactly 768px.
In simpler words:
Small screen (<768px) → width becomes full (w-full).
Medium screen (≥768px) → width becomes 768px (md:w-[768px]).
Let’s try resizing the website to 768px and above — you'll see the container switches from full width to a fixed 768px width.
